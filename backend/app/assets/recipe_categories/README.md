# Recipe category illustrations

These SVG files are **original assets** generated by Recipe Finder to match the
app palette (cream `#f8f5ed`, sand `#eee9dc`, sage `#7d9b78`, terracotta `#b65b3d`).

They are written on demand by `ensure_category_assets()` in
`app/services/recipe_images.py` and also live here once generated.

## Sourcing options (if you replace these)

| Source | License | Fit | Notes |
|--------|---------|-----|-------|
| **Keep these branded SVGs** (current) | Original / owned | Best brand match | Zero ongoing cost, no attribution |
| **One-time AI pack** (fal FLUX / GPT Image) | Check provider ToS | Strong if photo-like | ~15–25 images × ~$0.003–0.05 ≈ **$0.05–$1.25** total |
| [SVG Repo](https://www.svgrepo.com/) food vectors | Often **CC0** (verify each file) | Good icons | Recolor to palette before shipping |
| [OpenClipart](https://openclipart.org/) | **CC0** | Illustrations | Mixed quality; recolor |
| [OpenGameArt CC0 food icons](https://opengameart.org/content/cc0-food-icons) | **CC0** | Pixel/icon | Better for badges than hero cards |
| Unsplash / Pexels photos by dish type | License allows use; **not** CC0 in all cases | Photoreal | Attribution optional on Unsplash; less “cookbook cartoon” |
| Noun Project | Paid / attribution | Icons | Avoid unless subscribed |

**Do not** scrape Google Images or publisher cookbooks for the shared category pack.

## Replacing an asset

1. Drop a new `/{slug}.svg` (or `.webp`) into this folder with the same filename.
2. Keep viewBox roughly `800×500` for card aspect ratio.
3. Prefer SVG for crisp scaling; WebP if you switch to photos.
